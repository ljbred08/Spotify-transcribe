# Deploy pins (Render, Python 3.13 / Linux) — a freeze of the working dev
# environment, pruned:
#   - removed the editable self-install (`-e git+…#egg=refrain`) that freeze
#     picked up from the local `pip install -e .` — a cloud build cannot
#     clone the very repo it is building;
#   - removed pytest / pytest-asyncio (and their pluggy, iniconfig) — dev-only;
#   - removed the unused local-ASR cluster (faster-whisper, ctranslate2,
#     onnx-asr, onnxruntime, tokenizers, av) — transcription is cloud-only
#     and nothing in app/ imports them; their small transitive pins are kept
#     verbatim below, they are harmless;
#   - removed dead sfotipy (superseded by spotdl's matcher);
#   - shazamio_core pinned to 1.1.2, the version shazamio 0.8.1 itself
#     requires — the local 1.2.0 was only a Windows/py3.14 wheel workaround,
#     and pip's resolver would reject it next to shazamio==0.8.1 anyway.
#     1.1.2 ships cp313 manylinux wheels, matching PYTHON_VERSION on Render.
#   - aiofiles 23.2.1 and an unbounded anyio: shazamio 0.8.1 declares
#     aiofiles>=23.2.1,<24 and anyio>=4.3,<5 — constraints that were never
#     enforced in the local venv because shazamio was installed --no-deps
#     there. Nothing in app/ imports aiofiles directly; anyio 4.x serves
#     starlette/httpx as well as the 3.x it replaces.
#   - spotdl is NOT in this file: it pins fastapi<0.104 / uvicorn<0.24 (its
#     optional web UI's requirements, stale against 2026 releases) which
#     collides with the modern fastapi/uvicorn the app itself pins. The app
#     only uses spotdl's matcher/downloader, and it demonstrably runs against
#     fastapi 0.141 (the dev environment does exactly that) — so the Render
#     build installs it with --no-deps AFTER this file's resolve; every real
#     transitive dep it needs is already pinned here.
# On Windows / Python 3.14 for local dev, install shazamio differently —
# see the setup notes in the README.
